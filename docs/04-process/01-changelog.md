# Changelog

## [1.2.0] - 2025-05-20
### Added
- **Gemini Live API:** Real-time bi-directional voice assistant.
- **Multimodal Vision:** Camera integration in Live Assistant for environment scanning.
- **Internationalization (i18n):** Added support for Malay (MS), Indonesian (ID), Urdu (UR), and Turkish (TR).
- **Header:** Language selector moved to global header for accessibility.

### Changed
- **Map:** Integrated Google Maps Grounding via Gemini for creating dynamic markers.
- **Profile:** Added document OCR extraction using Gemini 2.5 Flash.

## [1.1.0] - 2025-04-10
### Added
- **Expense Tracker:** Multi-currency support (SAR/BDT).
- **Checklist:** Persistent state for Hajj rituals.
- **Thinking Model:** Integrated `gemini-3-pro-preview` for complex religious QA.

## [1.0.0] - 2025-03-01
### Initial Release
- Core Dashboard.
- Basic Translation (Text/Voice).
- SOS Screen.
- Health Tracker (Water/Meds).
- Offline PWA Support.
