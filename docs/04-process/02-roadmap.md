# Product Roadmap

## Q3 2025 (Post-Hajj Review)
- [ ] **Analytics:** Implement privacy-preserving usage analytics to understand drop-off points.
- [ ] **Wearable App:** Companion app for Galaxy Watch / Apple Watch for heart rate monitoring.

## Q4 2025 (Umrah Season)
- [ ] **Group Sync:** Allow family members to link profiles via QR code to see each other on the map.
- [ ] **Audio Guides:** Pre-recorded immersive audio history for Ziyarat sites.

## Q1 2026 (Hajj Prep)
- [ ] **Backend Migration:** Move from `localStorage` to Supabase/Firebase for cloud backup.
- [ ] **Agency Portal:** Web dashboard for Hajj Agencies to broadcast messages to their pilgrims.
